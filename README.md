# Excel Sales Analytics Dashboard

## Project Overview
An interactive Sales Analytics Dashboard developed using Microsoft Excel to analyse sales performance and generate business insights.

## Tools and Technologies
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Formulas
- Slicers

## Key Performance Indicators
- Total Sales
- Total Profit
- Total Orders
- Average Sales

## Analysis
- Regional Sales Analysis
- Category-wise Sales Analysis
- Product Sales Analysis
- Monthly Sales Analysis

## Dashboard Features
- Interactive slicers for filtering data
- KPI cards for performance monitoring
- PivotCharts for data visualisation
- Business insights and recommendations

## Business Insights
The project identifies top-performing regions, product categories and products, along with monthly sales trends and areas for improvement.

## Project Objective
To transform raw sales data into meaningful insights and support data-driven business decisions.
